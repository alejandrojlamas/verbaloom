## Final CLI correction

Six characterization tests reproduced missing CLI options, a saved pipeline
being ignored during resume, and an implicit `es-MX` locale even for French.
The prior `--max-cost` flag was only stored, not a pre-request reservation cap.
Both CLIs now accept these optional settings. Without them, other providers keep
their legacy behavior. `--max-cost` is an alias of `--budget-usd` and requires
`--max-calls`; invalid limits are rejected rather than silently ignored.

Examples from the installed repository, with keys configured only in the ignored
`.env` or the process environment:

```sh
# Nonbillable visibility check; no job or generation is created.
venv/bin/python translator.py translate /path/to/book.epub \
  --provider deepseek --model deepseek-v4-pro \
  --pipeline-preset compatible --preflight-only

# Normal DeepSeek-compatible execution with explicit gross USD / HTTP caps.
venv/bin/python translator.py translate /path/to/book.epub \
  --provider deepseek --model deepseek-v4-pro \
  --source-language English --target-language Spanish \
  --pipeline-preset compatible --budget-usd 5 --max-calls 500

# Resume reads the saved roles, editorial options and budget; no reset flags.
venv/bin/python translator.py resume RUN_ID

# The legacy entrypoint uses the same role/runtime contract.
venv/bin/python translate.py -i /path/to/book.epub \
  --provider deepseek --model deepseek-v4-pro \
  --pipeline-preset compatible --budget-usd 5 --max-calls 500
```

`--pipeline-config /path/to/pipeline.json` accepts the complete credential-free
pipeline snapshot used by the UI. Alternatively repeat, for example,
`--role audit openai gpt-6-luna low 4096`. Hybrid roles require both providers'
own credentials. `--review-policy source_audited_v1` remains experimental.
Do not combine legacy reviewer/translator/auditor model flags with role settings.
Choose a new job without pipeline flags, or Current configuration in the UI, to
return to legacy settings. Existing jobs keep their stored configuration.

The USD 5 example is an operational job cap, not permission to run a complete
book for the benchmark. The paid pilot remains separately capped at USD 5 across
providers, reviewers and retries. A visible model does not establish account
balance or successful paid generation.
